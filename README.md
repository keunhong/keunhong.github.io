# keunhong.github.io

- Feel free to borrow this template.
- Make sure to update all relevant fields in `_config.yml` and `_data`.

## Representative works

Add `representative: true` to a publication in `_data/publications.yml` to give
its row a soft yellow background. Omit the field or set it to `false` for a
standard row. The shared publication template applies the styling automatically
and labels representative works for screen readers.

Customize the color with `--color-surface-representative` in `_tailwind.css`.
